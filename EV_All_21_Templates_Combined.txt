================================================================
Date          : 26 October 2026
Team ID       : [TO FILL - not provided]

Student       : Abhay Singh (solo project)  [confirm name]

1. CUSTOMER SEGMENT(S)
   Students, learners and analysts who want to understand the EV market
   using data; evaluators reviewing the project.

2. JOBS-TO-BE-DONE / PROBLEMS
   Understand an EV dataset, compare vehicle attributes and find patterns
   without reading raw rows.

3. TRIGGERS
   An assignment / need to analyse EV data; interest in the growing EV
   market; seeing a visual dashboard that makes data easy to read.

4. EMOTIONS: BEFORE / AFTER
   Before: confused, overwhelmed by raw data.
   After: clear, informed, confident about patterns.

5. AVAILABLE SOLUTIONS
   Reading the dataset in a spreadsheet or table. Pros: full detail.
   Cons: hard to compare and find patterns quickly.

6. CUSTOMER CONSTRAINTS
   Limited time; no technical tools installed; needs a link that opens in
   an ordinary browser; free tools only.

7. BEHAVIOUR
   Searches the web, opens links, clicks charts and filters, compares
   values visually.

8. CHANNELS OF BEHAVIOUR
   8.1 ONLINE: opens the website, Tableau Public dashboards and story;
       GitHub repository for source code.
   8.2 OFFLINE: discusses results in class / presentations; printed
       project report.

9. PROBLEM ROOT CAUSE
   EV data has many attributes (sales, price, battery, range, ratings),
   so raw tables are hard to interpret and are not shown visually.

10. YOUR SOLUTION
   Interactive Tableau dashboards and a Tableau Story, collected on a
   website deployed on Render, with source code on GitHub.

================================================================
Date          : 26 October 2026
Team ID       : [TO FILL - not provided]

Student       : Abhay Singh (solo project)  [confirm name]
University    : Medi-Caps University, Indore, Madhya Pradesh, India

================================================================

PROJECT OVERVIEW
Objective : To analyse the electric vehicle (EV) market dataset and present
            the information through Tableau visualizations, two dashboards
            and a Tableau Story, shown together on a deployed website.
Scope     : Data inspection, analysis and visualization in Tableau; website
            development (HTML, CSS, JavaScript); version control with Git
            and GitHub; deployment on Render. Excludes backend, database,
            API, machine learning and automated data pipelines.

PROBLEM STATEMENT
Description : The EV market data contains many attributes (e.g. sales,
              price, battery, range, ratings), which are hard to interpret
              in raw form.
Impact      : Visual dashboards let users compare vehicles, recognise
              patterns and understand the market faster, and a public
              website makes the analysis easy to share.

PROPOSED SOLUTION
Approach     : (1) Understand the problem, (2) collect and inspect the
               dataset, (3) preprocess if needed, (4) analyse in Tableau,
               (5) create two dashboards, (6) create a Tableau Story,
               (7) build the website, (8) push to GitHub with Git,
               (9) deploy on Render, (10) test the published site.
Key Features : Interactive Tableau dashboards; Tableau Story presenting
               the analysis in sequence; single public website; source
               code on GitHub; deployment through Render.
